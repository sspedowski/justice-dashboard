Quick Start Guide

New to Justice Dashboard? Here's how to get started:

  1. Use the "Add Case" button to manually create a new case
  2. Or drag & drop PDF files to the upload area for automatic processing
  3. Use the search box to filter and find specific cases
  4. Click the export button to download your case data

⚡ Common Tasks

Adding a New Case

Click "Add Case" → Fill in case details → Click "Add Case" to save

Uploading Documents

Drag PDF files to upload area OR click "Upload PDF" → Select files → Wait for AI analysis

Finding Cases

Use the search box to filter by case ID, title, or status

Exporting Data

Click "Export CSV" to download all case data for backup or analysis

Need Help? Common Issues

PDF upload not working? Check file size (max 10MB) and ensure it's a valid PDF

AI analysis not working? OpenAI API key may be missing or invalid

Dashboard not loading? Check browser console (F12) for error messages

Authentication issues? Clear browser cookies and try logging in again
